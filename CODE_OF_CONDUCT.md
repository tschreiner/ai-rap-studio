# Code of Conduct

## Our standard

Be constructive, specific, and respectful. Critique code, contracts, tests, and creative artifacts rather than contributors. Harassment, threats, doxxing, discrimination, and publication of private source material are not acceptable.

Battle-rap language produced by the plugin is not a license to target contributors or protected characteristics. Repository collaboration must remain professional.

## Enforcement

Repository maintainers may edit or remove contributions and restrict participation when behavior or content violates this standard. Report conduct concerns privately to the repository owner.
